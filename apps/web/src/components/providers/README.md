Providers are composed once in App. API credentials stay in memory. Each new
connection owns a new TanStack Query client. Realtime invalidates durable reads;
it never executes SMS commands. Theme stores only the appearance preference.

Generated shadcn sources stay in ../ui; they are regenerated by the CLI. Route
screens and their private layout pieces live under ../../app. Query data belongs
to ../../queries; client view state and drafts belong to ../../stores.
